# TODO 模板

**用途**: 创建新的 TODO 文档（用于记录待办事项、Bug 跟踪、技术债务等）

**使用说明**:
1. 复制此模板到 `docs/scrum/todo/` 目录
2. 替换模板中的占位符（如 `{TODO_ID}`, `{summary}`）
3. 填写 TODO 的详细内容
4. 完成后归档到 `docs/scrum/todo/archive/` 目录

---

## 完成定义

每个 TODO 项完成时必须满足：

### 代码要求
- [ ] 代码已提交到功能分支
- [ ] 代码通过 Code Review
- [ ] 代码符合项目编码规范

### 测试要求
- [ ] 单元测试覆盖率 > 80%
- [ ] 所有测试用例通过
- [ ] 关键路径有集成测试

### 文档要求
- [ ] 相关文档已更新（如有变更）
- [ ] 注释清晰，逻辑自解释

# ASCII 线框图模板

用于 Frame 阶段快速勾勒页面布局。不需要 Figma，Markdown 中即可表达。

## 模板

```text
┌─────────────────────────────────────────────────────┐
│ [页面标题]                                           │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌────────┐ │
│  │ KPI 卡片1 │ │ KPI 卡片2 │ │ KPI 卡片3 │ │ KPI 卡4│ │
│  │  数字/状态 │ │  数字/状态 │ │  数字/状态 │ │ 数/状态│ │
│  └──────────┘ └──────────┘ └──────────┘ └────────┘ │
│                                                     │
├───────────────────────┬─────────────────────────────┤
│                       │                             │
│   [图表区域]           │    [列表/详情区域]           │
│   ECharts / D3        │    表格 / 时间线 / 卡片      │
│                       │                             │
│                       │                             │
├───────────────────────┴─────────────────────────────┤
│                                                     │
│  [底部操作区 / 分页 / 链路追踪]                        │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## 使用说明

1. 复制模板到设计文档或 Story 文件
2. 替换占位文字为实际内容
3. 标注每个区域的组件名称（方括号内）
4. 在区域下方用表格列出数据字段映射
